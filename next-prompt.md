A premium, data-rich AI News & Video Explorer Dashboard. The layout should feel like a command center for information, using a dark mode theme with neon accents to emphasize the 'AI' nature.

**DESIGN SYSTEM (REQUIRED):**
- Platform: Web, Desktop-first
- Theme: Dark, Sleek, Futuristic
- Background: Deep Obsidian (#0a0a0a)
- Surface: Dark Graphite (#1a1a1a) for component cards
- Primary Accent: Electric Indigo (#6366f1) for active states and primary buttons
- Secondary Accent: Neon Cyan (#06b6d4) for data visualizations
- Text Primary: Pure White (#ffffff)
- Text Secondary: Cool Gray (#9ca3af)
- Borders: Subtle indigo glow for active cards
- Shadows: Soft, deep shadows for layered effect

**Page Structure:**
1. **Navigation Sidebar:** Vertical menu with icons for 'Dashboard', 'Global News', 'Video Clips', 'Sentiments', and 'Settings'.
2. **Top Header:** Search bar with 'AI' branding and user profile/notifications.
3. **Summary Stats:** Four key metrics cards (e.g., 'Articles Today', 'Processing Speed', 'Viral Clips', 'Active Clusters').
4. **Primary Content Area:** 
   - **Left Column (66%):** Large grid of 'News Clusters'. Each card shows cluster name, number of articles, a mini sentiment sparkline, and a 'View Details' button.
   - **Right Column (33%):** 'Trending Video Clips' feed. Vertical scrollable list of vertical video thumbnails (16:9) with view counts and engagement scores.
5. **Footer:** System status indicator (Online/Processing) and copyright info.
